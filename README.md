This repository contains a list of **GeoAI** [university courses](geoai_courses.md) and [online courses](geoai_online_courses.md) (both incl. descriptions) as well as [degree programs](geoai_degree_programs.md).

Please create an issue or pull request if you like to add a course or a degree program to the lists, or update existing information.

Collected by the ICA Commission on GeoAI (https://geoai.icaci.org/).
