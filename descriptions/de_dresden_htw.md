# AI and Geodata Science

## Teaching Format

- Lectures and practical sessions using audio and visual media
- Practical exercises in computer laboratories
- Use of e-learning tools
- Practical presentations and student reports
- Development of a project involving problem-solving tasks

## Media and Materials

- Blackboard
- Lecture notes and scripts
- Projector presentations
- Exercise sheets
- Tutorials
- Demo videos

## Course Contents / Structure

- Big Data and Data Science
- Data analysis and data preparation
- Information integration
- Statistics, Data Mining, and Machine Learning

## Learning Objectives

Students acquire knowledge and practical skills in:

- Data acquisition
- Data cleaning
- Data integration

Students then learn how to generate new insights from heterogeneous datasets using data mining and machine learning methods and how to present these results in a spatial context.

In addition, students acquire fundamental knowledge of machine learning, including:

- Supervised learning
- Unsupervised learning
- Reinforcement learning

Students also implement a concrete practical application.

## Social and Personal Competencies

Students develop social and self-management competencies through collaborative work, presentations, and independent project development.
