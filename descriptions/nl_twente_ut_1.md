# Machine Learning for Geospatial Sciences

## Course Content

This course focuses on how machine learning techniques can be leveraged to extract meaningful patterns and support decision-making using geospatial data. The course provides both theoretical foundations and practical applications.

It is designed for learners with:

- Strong Python programming skills
- Basic knowledge of machine learning
- A solid understanding of mathematics, including:
  - Probability
  - Calculus
  - Linear algebra

Participants begin with an overview of machine learning concepts, including:

- Supervised learning
- Unsupervised learning

Special emphasis is placed on geospatial applications such as:

- Agriculture
- Environmental monitoring

The following algorithms are covered:

- Support Vector Machines (SVM)
- Decision Trees
- Random Forests
- XGBoost
- Neural Networks

The course strongly emphasizes geospatial feature engineering. Students learn how to extract and encode features from raster and vector datasets, including:

- Spectral indices
- Spatial texture
- Topographic features
- Temporal features
- Zonal statistics

Students also apply dimensionality reduction and feature selection techniques such as:

- Lasso
- Recursive Feature Elimination (RFE)

Advanced topics include:

- Ensemble learning:
  - Boosting
  - Bagging
  - Stacking
- Clustering methods:
  - Self-Organizing Maps (SOM)
  - Gaussian Mixture Models (GMM)
  - Co-clustering
- Ethics in AI for geospatial applications:
  - Bias
  - Fairness
  - Transparency

Throughout the course, learning is supported through:

- Hands-on exercises
- Practical sessions
- Quizzes
- Discussions

Practical exercises involve working with real-world datasets to solve complex problems and encourage responsible and impactful use of geospatial machine learning in environmental and social contexts.

## Course Objectives

At the end of this course, students will be able to:

- Perform exploratory data analysis to improve understanding of available datasets
- Select appropriate datasets for geospatial applications using machine learning algorithms
- Perform feature engineering by selecting, manipulating, and transforming raster and vector geospatial data into machine-learning-ready features
- Properly partition labeled datasets for:
  - Training
  - Hyperparameter tuning
  - Accuracy assessment
- Explain the machine learning algorithms covered in the course, including:
  - Clustering
  - Classification
  - Regression
- Apply machine learning algorithms to support various geospatial applications
- Interpret prediction results and evaluate the generalization capability of machine learning models

## Assessment Plan

- Project Assignment: 70%
- Written Exam: 30%

## Participation Requirements

- Python programming skills
- Basic mathematics skills
- Basic statistics skills
