# Introduction to Geospatial Artificial Intelligence: The Remote Sensing and GeoAI Frontier

## Course Description
This course introduces the fundamental concepts of remote sensing and machine learning, providing students with hands-on experience in Python programming. Students learn to automate remote sensing data processing and train traditional machine learning models for practical geospatial artificial intelligence applications. Additional coursework is required for those enrolled in the graduate-level course.

## Course Learning Outcomes
1. Understanding GeoAI Fundamentals: Define and explain the fundamental concepts of GeoAI, including geospatial data, spatial analysis, and artificial intelligence.
2. Geospatial Data Processing with Python:Utilize Python for geospatial data manipulation and analysis. Apply Python libraries for tasks such as data loading, transformation, and visualization.
3. Integration of Geospatial and AI Technologies: Explore the integration of geospatial technologies with artificial intelligence (GIS, remote sensing, and machine learning).
4. Machine Learning for Geospatial Data: Explore machine learning algorithms applicable to geospatial data. Apply supervised and unsupervised machine learning algorithms to analyze and interpret spatial patterns in geospatial datasets, with a focus on classification techniques,
5. Hands-on Programming Skills: Develop practical programming skills using relevant programming languages and libraries for implementing GeoAI algorithms.
