# GeoAI and Machine Learning

## Goals, Contents, and Teaching Methods

### Goals
Geospatial Artificial Intelligence (GeoAI) is an advanced graduate-level course in spatial data science covering methods and techniques widely used in Cartography and Geoinformatics. The primary focus of this course is on geospatial data-driven modeling.

The course introduces spatially explicit machine learning methods in geospatial AI, including:

- Spatial clustering
- Spatial autoregressive regression
- Geographically weighted regression
- Classification methods for geospatial data

Applications include georeferenced social media data, GPS trajectories, remote sensing images, and other geospatial datasets across various domains.

The course also introduces spatial data processing methods and tools for preparing geospatial data (vector and raster formats) for machine learning workflows using Python programming.

### Contents
The course covers the following topics:

1. Introduction to Artificial Intelligence (AI), GeoAI, and Machine Learning (ML)
2. Different algorithms in ML (Supervised, Unsupervised, Regression, Classification)
3. Geodata preparation for machine learning
4. Understanding different types of learning algorithms
5. Introduction to deep learning
6. Explainability in GeoAI

### Methods
- Theoretical explanations
- Hands-on exercises
- Group work
- Presentations
- Discussions

## Type of Assessment and Permitted Resources

Upon completion of the course, students are expected to:

- Understand concepts, methods, and techniques in spatial data science
- Construct machine learning workflows using different types of geographic data
- Become familiar with Python programming for geospatial data processing
- Solve practical geospatial problems using machine learning and spatial analysis methods

## Minimum Requirements and Evaluation Criteria

### Course Assessment
Course grades are based on:

- Exams
- Assignments
- One final project
- Class participation, including attendance and group discussions

Assignments require Python programming based on lecture materials.

### Minimum Requirements
- Compulsory attendance (maximum two absences allowed)
- Mandatory presentation of project work
- Completion of project work after acquiring course competencies
- Basic knowledge of Python programming

### Evaluation Criteria
| Component | Points |
|---|---|
| In-class assignments | 10 |
| Final exam | 50 |
| Project presentation | 30 |
| Active participation in discussions | 10 |

A positive grade requires an overall score of at least **51%**.

## Examination Topics

- Content of the course units and presentation slides
- In-class assignments
- Presentation of the final project

### Final Report (Approx. 10 Pages)
The final report should include:

- Introduction
- Data
- Methods
- Results and Discussion
- References
